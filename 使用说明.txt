PDF 工具箱 · 单机版 使用说明
================================

两个版本
--------
桌面图标：
  「PDF工具箱」        精简版  160 MB  18 项功能
  「PDF工具箱-完整版」 完整版  301 MB  19 项功能（多一个 PDF 转 Word）

两者唯一区别：完整版多「PDF 转 Word」。其余完全一样。
两个都是文件夹，拷到别的电脑要整个文件夹一起拷。

  D:\PDF工具箱\精简版-160MB\PDFToolBoxLite.exe
  D:\PDF工具箱\完整版-301MB\PDFToolBox.exe


功能清单（19 项）
-----------------
【整理】
  合并 PDF      多份按顺序拼成一份，可上移/下移调整顺序
  拆分 PDF      每 N 页一份，或自定义分组（如 1-3|4-6|7-）
  提取页面      挑出指定页（如 1-3,5,7-9）
  删除页面      去掉不要的页（如 2,5-7）
  页面排序      按表达式重排，如 3,1,2,4- 表示第3页在前其余顺延
  旋转页面      把倒了的扫描页转正（90/180/270，可只转某几页）

【转换】
  Office 转 PDF   Word/Excel/PPT 转 PDF，可批量（调用本机 Office，质量最高）
  PDF 转图片      每页导出 PNG/JPG，DPI 可调
  图片转 PDF      多张照片合成一份，可选 A4 居中
  PDF 转 Word     仅完整版
  PDF 转文本      提取文字存 txt

【优化】
  压缩 PDF      三档：无损重排（推荐）/ 中等 / 强力
  修复 PDF      打不开、提示损坏的文件尝试修复

【编辑】
  添加页码      位置（顶部/底部 × 左中右）、格式（第X页 / X/Y / -X- / 纯数字）
  裁剪 PDF      按边距裁掉四周白边或扫描黑边（单位 pt，1mm≈2.83pt）
  标记密文      把指定关键字**彻底涂黑删除**（文字层也删，不可还原）
  比较 PDF      两份文件逐页对照，生成并排比较图并标出差异页

【安全】
  加密 PDF      设打开密码（AES-256）
  解除密码      知道密码时去掉加密
  添加水印      加「XX公安局 案件材料」，可同时加页码


与 iLovePDF 30 项功能的对照
---------------------------
已覆盖 22 项：
  排列：合并、拆分、删除、提取、排列（5/6，扫描为PDF 用「图片转PDF」替代）
  优化：压缩、修复（2/3）
  转为PDF：JPG/图片、WORD、PPT、EXCEL（4/5，一个 Office转PDF 顶三项）
  转出：PDF转JPG、PDF转WORD（2/5）
  编辑：旋转、页码、水印、裁剪（4/6）
  安全：加密、解锁、标记密文、比较（4/5）

未做 8 项，原因：
  OCR 识别         需要额外识别引擎，体积 +200MB 以上（见下）
  HTML 转 PDF      需要内置浏览器内核，+150MB
  PDF 转 PPT       需专门引擎，且转换质量普遍很差
  PDF 转 EXCEL     同上
  PDF 转 PDF/A     需 Ghostscript 组件
  编辑 PDF 内容    需要商业级 PDF 编辑器内核，做不了
  PDF 表单         同上
  PDF 签名         需要数字证书体系，且法律效力另议

如果确实需要 OCR（扫描件转可搜索文字），说一声，我单独做一个
OCR 版——目前最靠谱的本地方案是 RapidOCR（中文识别好、离线），
体积会增加 200MB 左右。


怎么用
------
1. 左侧点选工具
2. 点「选择文件」（合并 / 图片转PDF / Office转PDF 可多选；比较 PDF 需选 2 个）
3. 中间填参数
4. 输出位置留空 = 存到原文件旁边
5. 点「开始处理」


几个办案常用场景
----------------
· 多份笔录合成一卷：合并 PDF → 上移/下移排序 → 开始
· 扫描卷宗加页码：添加页码 → 底部居中 → 格式「第 X 页」
· 材料外发前脱敏：标记密文 → 填「张三,620422198410067753」→ 涂黑
                   （真删除，对方用工具也提取不出原文）
· 卷宗太厚传不上：压缩 PDF → 中等
· 扫描件有黑边：裁剪 PDF → 上下左右各填 20~40
· 两份材料比对：比较 PDF → 先选基准版，再选修改版
· 打印前排版：Word 里排好 → Office 转 PDF


注意事项
--------
1. Office 转 PDF 需要本机装有 Word/Excel/PowerPoint（已检测到本机有）
2. 标记密文只对**有文字层**的 PDF 有效。扫描件是图片，搜不到文字，
   需先做 OCR 才能涂黑
3. PDF 转 Word 对扫描件效果差
4. 「强力压缩」会把文字变成图片，之后搜不到、选不中，非必要别用
5. 加密后密码要记牢，忘记无法恢复
6. 处理几百页大文件时界面会停在一处，属正常，别关窗口


关于 360 提示
-------------
本软件由 Python 打包，360 会做启发式检查，可能出现误报。
已做处理：文件夹版（不自解压）、写入正规版本信息、声明不需管理员权限。
若仍弹窗，加白名单即可（只影响这一个文件）：
  弹窗里把「阻止」改成「允许程序运行」，勾「不再提醒」
  或 360 → 木马查杀 → 信任区 → 添加文件
